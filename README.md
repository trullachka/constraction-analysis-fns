
# Анализ строительной отрасли России

## Цель исследования

Оценить финансовое состояние и перспективность
сегмента строительства жилых и нежилых зданий
среди малых и средних предприятий России.

## Данные

Источник: ФНС России.

ОКВЭД: 41.20 — Строительство жилых
и нежилых зданий.

Период финансового анализа: 2021–2023 годы.

## Используемые инструменты

- Python
- Pandas
- Requests
- Matplotlib
- GeoPandas
- Jupyter Notebook

## Содержание исследования

1. Подготовка реестра компаний.
2. Получение бухгалтерской отчетности ФНС.
3. Расчет финансовых показателей EBIT.
4. Анализ изменения чистой прибыли.
5. Географический анализ топ-500 компаний.
6. Выводы о состоянии отрасли.

## Основные результаты

Совокупный EBIT увеличился на 94,4%
за 2021–2023 годы.

Доля компаний с ростом чистой прибыли
за 2021–2023 годы составила 47,33%.

Наибольшая концентрация крупнейших
по выручке компаний наблюдается
в европейской части России.

## Ограничения

EBIT рассчитан приближенно на основе
доступной бухгалтерской отчетности.
Для полной EBITA необходимы дополнительные
данные об амортизации нематериальных активов.
